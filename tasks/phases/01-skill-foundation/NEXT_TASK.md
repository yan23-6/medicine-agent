# T02 中医知识与病例蒸馏 Skill 及金标准闭环

> 状态：draft  
> 只有 T01 验收通过后才能提升为 ready

## 目标预告

在已实现的 Skill 运行时和最小生产消费闭环上，设计并实现中医知识与医案的专业蒸馏能力。任务同时制作小型人工金标准，用于定义正确输出和评价 Skill，而不是先生成正式知识包。

预计范围包括：

- 选择首个中医专题、教材片段和少量医案；
- 形成来源、证据、四诊、病因、病位、病性、病机、证候、治法、方药和诊次标注；
- 实现 CaseDistillationSkill 和 TCMReasoningSkill 的首个可调用版本；
- 形成支持、弱证据、反证、缺失、主次、兼夹和动态变化；
- 将 Skill 输出与人工金标准比较；
- 修正逻辑 Schema 和 Skill 接口；
- 使用 T01 的 Build、Validate 和 Query 验证结果可生产、可校验、可消费。

本任务正式启动时，需要根据 T01 的真实代码、Schema、错误分布和可用材料重写为完整需求，当前内容不能直接执行。
