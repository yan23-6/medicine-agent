# 阶段 01 Skill 基础与最小生产消费闭环

> 阶段状态：done（2026-09-29）
> 当前任务：T01 收尾：契约补全与阶段验收

## 阶段目标

从只有设计文档的状态开始，建立可注册、可调用、可校验、可测试的 Skill 运行基础，并用最小测试材料跑通“材料—证据—知识对象—实验知识包—查询—来源回溯”。

本阶段解决“用什么蒸馏”和“如何证明蒸馏结果可用”，不追求完整中医语义、批量材料或多 Agent。

## 当前检查点（2026-09-29）

运行骨架、6 个最小 Skill、9 个 CLI 命令、版本化 Schema、运行记录、完整 Facade、字段歧义和多证据闭环已经实现。当前环境和新隔离环境测试均为 `15 passed`，wheel/sdist 构建及 wheel 独立安装闭环已经通过。

真实 LLM 显式冒烟、真实模型最小流水线、包校验、查询和证据回溯已经通过。首次真实流水线输出不符合 Schema 时被正确阻断，重跑后完成闭环；该非确定性已记录为下一阶段的受控重试要求。

- 当前机器已安装 uv 0.12.18 与 uv 管理的 CPython 3.13.15；其他机器必须按项目版本与锁文件恢复环境；

- 详细选择见 [TECHNICAL_DESIGN.md](TECHNICAL_DESIGN.md)。

## 阶段完成门

- Skill 的身份、版本、输入输出、错误和测试契约可执行；
- 存在 Skill 注册、发现和调用入口；
- 存在提供商无关的模型适配接口及无需外部密钥的测试替身；
- 最小材料摄取、证据定位、知识蒸馏、包构建校验和包查询 Skill 可运行；
- 实验知识包可以生成、验证、重新读取和回溯证据；
- 重复执行具有稳定身份，不产生无控制重复数据；
- 干净环境可以按文档运行自动测试；
- 尚未实现的医学能力返回明确错误，不由模型自由补足。

## 本阶段不做

- 不蒸馏整本教材；
- 不生成正式知识包；
- 不实现多个 Agent；
- 不接入 LadybugDB 正式工作库；
- 不固定最终知识包封装格式；
- 不实现完整中医、西医、方剂或针灸能力；
- 不开始后训练。
