# 阶段 02 当前任务草案

> 状态：draft  
> 预定任务：T02 中医知识与病例蒸馏 Skill 及金标准闭环

## 预定目标

选择一个范围明确的中医专题，使用教材片段、医家经验片段和少量医案建立人工金标准，并实现能够产生同类结构结果的 CaseDistillationSkill 与 TCMReasoningSkill。

## 预定需求

- 首先确认病种或专科、医家、材料许可和病例范围；
- 金标准先于正式知识包，由人工与专家审核；
- Skill 必须通过阶段 01 的注册、调用、Schema、错误和测试协议；
- 教材知识、医家观点、病例事实和模型候选分别保存；
- 病机路径包含证据、主次、兼夹、时序、反证和缺失；
- 原始医案先构造成 CanonicalCase，再进行中医推理；
- 输出经过知识包 Build、Validate、Query 和 Trace；
- 不合格结果不能进入正式包。

## 启动前必须补写

进入本阶段时，应根据真实 Skill API、第一阶段错误、可用材料和专家条件，补齐精确输入输出、样本规模、评价指标、产物路径和验收阈值。当前草案不得直接作为实现规格。
