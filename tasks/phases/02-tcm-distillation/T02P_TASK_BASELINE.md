Codex 是开发工具，不是运行依赖。用户无需开发仓库、开发会话或开发者账号；模型及必要识字资源由产品的独立部署配置提供。

整体产品还包括基于这些数据包的问诊辅助，遵守现有医学边界。本任务完成资料入口和数据包消费接口，不把普通关键词查询或通用聊天宣称为问诊已经实现。后续问诊复用相同包、证据、版本和病例事实。

T02-A 仍为 review，新需求不是用户确认其验收。其原任务原文保留在 `T02A_TASK_BASELINE.md`，验收报告不改写。T02-P 是资料入口补缺，不依赖 T02-A 医学验收；T02-B 和问诊仍需各自医学与安全验收。

## 4. 首批格式与能力声明

| 输入 | 本任务必须支持的范围与定位 |
| --- | --- |
| PDF | 文本页、扫描页、混合页；物理页码、页面大小和文字块区域 |
| DOCX | 段落与表格单元格、结构路径；嵌入图片经 OCR；不伪造固定页码 |
| TXT / Markdown | 明确编码策略、行/段位置与结构路径 |
| PNG / JPEG | 中文文字识别、像素区域和图片指纹 |

接收单文件或文件清单，识别真实类型，扩展名不符、损坏、加密或未知格式返回明确结果。文件清单可顺序执行，任务按文件隔离；不要求本次完成高并发批处理。电子表格、HTML、EPUB 等后续按适配器扩展，能力清单明确其尚不支持，不能宣称所有格式已实现。

OCR/PDF/DOCX 库与模型资源需查官方文档，实际验证许可、Windows/Python 3.13 和独立部署，再锁定依赖。优先本地中文 OCR，可封装独立运行时；远程服务显式配置。现有文本模型不默认具有视觉能力。

## 5. 实施顺序与接口

1. 建立文件接收、格式探测与适配器能力清单；定义来源位置、任务单元、检查点和实验修订契约。新增语义先登记唯一 `semantics/registry.json` 并升级契约，再改模型和快照。
2. 实现持久化工作区、逐单元处理及暂停/恢复；扩展真实材料提取和 OCR，保存原始证据。
3. 接入内容分析、候选构建、校验、查询回溯和不可覆盖的实验修订；实现包根目录发现、兼容检查、版本选择和基本跨包查询。
4. 工具登记并通过上述检查后，接入总智能体到资料处理小智能体的真实父子任务，使用相同核心接口。
5. 构建发行物，在独立安装环境运行全部链路；完成中断恢复、复制包和目录发现验收。

提供中立程序接口与 CLI：提交文件、列出能力、查看进度、暂停、恢复、查询任务结果、设置/刷新包目录、列包、选用版本、查询和追溯。具体名称在实现时固定并给出可复制用法，本文不冒称命令已经存在。未来 Web/MCP/REST 复用接口。

任务输入包含文件或清单、选择范围、来源信息与允许用途、工作目录与包目录、OCR/分析配置、预算及超时；更新显式给出目标包和父修订。允许逐步处理完整文件，不强迫只选几页；资源额度不足时暂停并可续跑。

返回任务和父子身份、各单元/阶段进度、实际读取方式、已完成范围、失败与待核项、包与父修订身份、路径、差异、校验和查询回溯结果。不可用内容明确报告，空页、零知识或失败不伪装完整成功。

## 6. 内容分析与证据

按片段区分教材、论文、医家经验、病例和表格；调用适用的已验收能力，超出医学基线范围保持原始证据与待核候选。不能把整本书都按胸痹病例模板处理。

每条候选知识与关系引用真实证据。记录来源指纹、稳定身份、页/段/表格/区域、坐标单位、原点、旋转、缩放；区分 PDF 物理页码与印刷页码。OCR 原值、纠正候选、模型解释、人工审核分别保留，无法映射字段不丢弃。

模型伪造引用必须阻断。低质量文字、阅读顺序、未恢复图表或跨页歧义有明确记录；不能为了通过格式校验丢弃内容或猜测作者、版次、剂量和医学结论。医学结果默认未审核。

## 7. 持久化暂停与恢复：本次硬门

- 以文件指纹、处理范围和关键配置确定任务输入；按页/段/块及提取、OCR、分析、构建阶段保存状态、版本、输出身份和校验信息。
- 暂停停止新单元派发，保存可提交结果；状态能够区分暂停中、已暂停、失败、恢复中、已完成，不依赖模型聊天记忆。
- 进程终止后，重新启动只从最早未提交单元的未完成阶段继续。已完整提交的 OCR/分析不重复调用；外部调用已发生但未提交时可重试，记录可能重算，不虚称恰好一次计费。
- 200 页书，第 100 页完整提交则从 101 页继续；第 100 页只完成 OCR 则从该页分析阶段继续。分页数不等于知识分析完成数。
- 检查点与输出采用原子提交策略；处理缓存损坏、写到一半、遗留运行状态和重复恢复，防止两个写入方同时恢复同一任务。
- 路径变化可用内容指纹重新绑定。文件、工具、模型/提示、协议或关键配置变化须明确失效范围或新建任务，不能混用历史结果；可兼容重用哪些阶段须可检查。
- 跨页上下文和章节边界持久化，重叠片段去重，保证恢复后跨页知识不遗漏、不重复计入。
- 完成前只显示阶段成果；若导出部分候选包，明确处理/缺失范围。不能将未完成的新修订替换旧版完整结果。

## 8. 文件夹包使用、迁移与更新：本次硬门

包必须保存科目/专题、资料类型、专业 Profile 和适用的中医三层归属、分类依据及声明/候选/未分类状态，支持多分类。格式不是分类；缺少资料不得猜测。目录支持分类筛选，复制包和追加修订保留分类，验收覆盖“迁移后按分类查询”和旧包未分类兼容。字段意义以唯一语义注册表及 `schemas/t02p/` 为准，不另建竞争字典。

以用户配置的包根目录发现多个实验包，启动或显式刷新即可识别，校验兼容版本、完整性、重复身份及质量范围，显示可用/待核/隔离状态。符合当前研究使用范围的版本自动纳入查询，无需改提示词、手写注册表或逐包解释。多个修订默认选择最后一个成功提交且符合使用范围的修订，保留显式固定版本能力；冲突不猜测。

完成包自包含知识、关系、必要原文/OCR 证据文本、来源位置、处理范围、审核与版本等信息。资源采用相对引用，不能依赖开发机绝对路径、会话 URL、任务缓存或旧工作库。原始文件可因许可/体积不附带；此时仍能读证据文本与出处，视觉核验另行提示。

在另一隔离路径或兼容电脑，只复制完成包目录即可发现、校验、基本查询与回溯，无需原始文件、任务工作区或 Codex。索引可重建，缺少生成模型不影响已有包的基本查询。迁移未完成任务则另外携带输入、检查点和所引用中间文件并验证版本，不要求只复制完成包就能恢复未完成任务。

新来源新建包；同来源追加页或重分析生成不可覆盖修订，记录父修订、输入指纹和变化，保留旧版。相同任务重试不重复提交；临时构建、校验、查询、回溯、重新读取全部通过后才提交选用，失败不破坏旧版。源码和发行物内置统一解释规则，包不携带任意可执行代码。

这次提供实验目录级实现，阶段 03 仍负责冻结正式格式、LadybugDB 和完整索引；不能以阶段 03 未完成为由推迟本次复制可用验收。

## 9. 产品独立运行与父子智能体：本次硬门

总智能体创建真实可持久化子任务；资料处理小智能体只调用已实现登记的兼容工具。父子记录可追踪、失败回传、暂停恢复后身份连续。可共用进程或模型，不能只给函数改名或靠提示词伪装 Agent。

发行物包含实现、语义注册表、工具声明、Schema 与必要运行资源；OCR 模型资源须随发行或有受控准备说明。模型和服务配置通过产品自己的入口提供，不继承 Codex。独立安装后，从非仓库目录运行，不读取开发源码、`.venv` 或开发缓存，不需要 Codex 应用/MCP 工具。目标平台先验收当前 Windows，其他系统不未经检查宣称支持。

有模型配置才执行实际语义分析；无模型配置返回明确能力状态，已有包仍可进行确定性查询。独立运行与完全离线运行分别说明。
