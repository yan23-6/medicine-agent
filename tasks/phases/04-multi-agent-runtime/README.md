# 阶段 04 多智能体运行时与西医兼容

> 阶段状态：idea  
> 进入条件：核心 Skill 和知识包查询稳定

## 阶段目标

在已经可调用的 Skill 上建立最小多智能体编排，完成中医、西医和安全路径围绕同一标准病例的并行协作，并验证通用主干没有被写死为中医结构。

## 阶段完成门

- 三个初始 Agent 的职责、权限和状态可执行；
- Agent 只能调用注册表中的兼容 Skill；
- 中医、西医和安全路径共享病例事实但不混淆概念；
- 安全门具有阻断与降级能力；
- Agent 路由、Skill 调用和结果汇总可审计；
- 单体工作流与多 Agent 方案有可比较基线。
