# 同用户更新与跨用户数据包联合使用

> 稳定需求：2026-10-15 用户明确授权。建设状态以 tasks/STATE.md 及 T02-B2 验收为准。

## 用户所说的“训练数据”

这里指用户用资料分析 Agent 构建的知识数据包，不是模型权重后训练。用户归属只限制更新和分析缓存复用，不限制已放入同一根目录的兼容包联合使用。归属 ID 为本地声明的稳定标识，不是登录认证或访问控制。

## 同用户更新

仅在归属明确且相同时，允许复用已完成分析。复用还须校验原文件指纹、分析/识字工具和模型配置、来源元数据、所选页及相邻页上下文。新增页改变旧页上下文时，相关旧页也须重分析；不能机械声称永远只处理新增页。

归属不同拒绝把另一个用户的包当父版本/分析缓存；不根据书名、同名知识或相似文本猜同一来源。旧包归属未知仍可查询，不能自动冒认为某用户并复用。既有无归属旧任务可保留兼容的完整重分析，不具备新缓存复用资格。

## 第二份资料与原文

同一用户提供第二份不同资料，默认生成独立来源包，不能继承第一份资料的原文或覆盖其解释。每份资料保存实际提取/OCR原文、证据位置、资料身份、处理范围和不确定项；可关联相同知识，分类并集是查询视图。不同来源即使逐字相同也不把其他材料的文字当成本次提取结果。

已更正包不得用旧模型缓存覆盖更正。未具备安全的更正续接时，应在提交时明确拒绝该父包的增量复用；仍保留可查询结果，新资料可独立分析。不得静默退回原模型值。

## 跨用户热插拔

两个或更多用户的数据包放入同一根目录或其用户子目录，兼容的已选用版本进入同一查询和关联范围。一次任务可联合读取内容、原文及沿多级关联继续查询，使用与单包相同的稳定包/节点地址。用户ID不能成为查询隔离条件。

源节点独立；同文件由两用户各自产出也有独立的归属包身份，不抢占彼此版本。名称相同只给候选关联，不自动认定相同含义。显式关联可跨用户、跨包并成链，循环去重；未启用或缺失目标保留状态，其内容不进入检索和关联结果。递归发现用户目录的 links，校验并去重，不绕过包校验或版本选择。

完整迁移复制整个数据根目录，含各包与 links/reviews。单个完成包自带原文证据，可独立读；需要携带的外部联系不能凭开发机路径恢复。临床推理和数据库功能仍按各阶段验收。

## 本轮接口与验收边界

新增独立 owned-analysis 操作契约：带 owner_id 的任务、受校验和保护的归属与逐单元分析缓存。沿用旧 AnalysisRequest/PackageRevision 契约读取旧任务，新增能力用扩展模型和单独 Schema 表达，不另建医学字段字典。创建包和增量更新在产品自身运行时完成。

先自制不同用户/两份资料与多页文件验证归属隔离、缓存命中/失效、断点恢复和跨包多级关联，再做独立安装迁移验证。真实测试三页可以替换或清理，不构成保留这些测试结果的产品要求；生产包的原文、不同来源和关联仍按稳定契约保存。


## 操作字段说明（医学字段字典不变）

| 字段 | 含义 |
| --- | --- |
| owner_id | 构建用户/数据归属的稳定声明ID，建议每人不同 UUID；只约束资料更新复用，不隔离查询，不是患者ID或认证。 |
| content_package_id | 包装用户归属前，由真实来源、证据及知识内容计算的基础身份；不同用户再得到各自包ID。 |
| source_id / source_sha256 | 原始资料身份和内容指纹，判断是否同一资料，不能用标题代替。 |
| runtime | 当时语义、工具、解析/OCR适配器、分析策略和模型标识/配置指纹；不包含密钥。 |
| options_fingerprint | 分析方式、强制OCR、来源元数据和使用声明的校验指纹；不同时拒绝静默混用旧分析。 |
| document_unit_count | 原资料实际总页/段数，用来验证范围及结构。 |
| units.ordinal / predecessor_unit | 本单元页/段号及实际使用的相邻前一单元；用于上下文失效判断。 |
| units.extraction | 实际提取/OCR文本块、方法、置信度和位置；保留原文。 |
| units.analysis | 已提交的本页证据、片段、知识/关系、中医结构和警告；逐一与包内容核对。 |
| reused_from_package_id | 本次复用的父包身份；没有复用父包时为空。 |
| reused_analysis_units | 本次完整复用分析的单元号，不包含已失效或后来恢复时重算的单元。 |
| reused_extraction_units | 本次复用提取/OCR的单元号；可能仍需重新分析。 |
| invalidated_context_units | 因新增相邻页改变上下文而重分析的已有单元号。 |

这些字段由 domain/owned_analysis.py 和独立 Schema 维护，不在包内重定义医学字段含义；195 个医学/公共语义字段的唯一注册表和自动说明书保持原版本。
