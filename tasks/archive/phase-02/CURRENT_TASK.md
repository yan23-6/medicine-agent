## 背景与实际前置

B6 已证明旧格式模拟包可动态生成多维视图，并完成局部图、候选关联和失败隔离的软件验收。本机复核确认教材 PDF 与 Python 环境存在，但工作区及 Git 历史中没有真实 B4/B5 `.medpkg`，不能冒称对旧文件完成复验。

本任务改走最小返工路径：使用历史已核验范围物理页 34—38 做本地代表性重建。先在产品自身运行时完成本地 OCR、持久化检查点和原文定位；只有模型阶段获得明确许可后才发送对应 OCR 文本。不得扩大到整书。

## 目标

1. 以真实教材页验证当前读取、OCR、证据定位和断点能力仍可工作；
2. 形成可继续执行的模型分析检查点，不因等待许可重复 OCR；
3. 完成模型阶段后生成当前格式 `.medpkg`，核验多维视图、受限局部图、异名候选、隔离审计和单文件迁移；
4. 与 B4/B5 历史验收中的来源范围、OCR数量及质量边界比较，但不伪造旧包逐字兼容结论；
5. 只有真实证据或关键语义缺失时才局部迁移或重提，不重跑整书。

## 输入与边界

- 输入：`pdfs/15086322中医基础理论.pdf`，物理页 34—38；
- 本地阶段：PDF 检查、页面提取/OCR、位置与检查点持久化；
- 外部阶段：未经本任务单独明确许可，不发送 PDF、页面图像、OCR、提示词内容或医学候选；
- 输出只进入被忽略的 `artifacts/b7-real-compat/`，PDF、运行产物和本地配置均不提交；
- `config/llm.local.toml` 仅允许产品运行时读取，任务记录不得包含密钥、请求头或错误正文。

## 实现与验收

1. 记录 PDF 指纹、页数、选择范围及本地 OCR 结果摘要；
2. 验证任务暂停后可从检查点读取，不重复已完成 OCR；
3. 若获得外部模型许可，恢复同一任务完成分析和包构建；否则明确停在“等待模型分析许可”，不得用 FakeModel 冒充；
4. 成包后核验来源/证据可追溯、`tcm-knowledge@0.2.0`、多维过滤、局部图边界、异名候选不自动合并、`rejected_candidates` 可携带；
5. 复制单个包到隔离目录后，在没有原 PDF、旧工作区和本地配置的条件下重复查询；
6. 形成 `T02B7_ACCEPTANCE.md`，同步 STATE/HANDOFF。只有上述成包检查真实完成才可标记 done。
