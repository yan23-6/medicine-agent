# 历史任务档案

本目录保存已经结束、被替代或仅代表某一时点的任务、技术稿和验收报告。

使用规则：

- 可用于追溯决策和验证当时结果；
- 不得作为当前任务、当前文件存在或当前能力可用的证明；
- 与 `tasks/STATE.md`、实际代码或产物冲突时，以后者为准；
- 历史外发许可、路径、任务 ID 和本地配置状态不自动延续；
- 原则上不重写历史验收结论，只在档案索引中解释其时点。

目录：

- `phase-01/`：Skill 基础阶段的任务、设计和验收；
- `phase-02/`：中医蒸馏阶段已结束或被替代的任务与验收；
- 根目录外的 `archive/legacy-design/`：项目早期长篇评审稿和阶段记录。
