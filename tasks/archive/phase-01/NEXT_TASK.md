## 目标预告

在已实现的 Skill 运行时和最小生产消费闭环上，设计并实现中医知识与医案的专业蒸馏能力。任务同时制作小型人工金标准，用于定义正确输出和评价 Skill，而不是先生成正式知识包。

预计范围包括：

- 选择首个中医专题、教材片段和少量医案；
- 形成来源、证据、四诊、病因、病位、病性、病机、证候、治法、方药和诊次标注；
- 实现 CaseDistillationSkill 和 TCMReasoningSkill 的首个可调用版本；
- 形成支持、弱证据、反证、缺失、主次、兼夹和动态变化；
- 将 Skill 输出与人工金标准比较；
- 修正逻辑 Schema 和 Skill 接口；
- 使用 T01 的 Build、Validate 和 Query 验证结果可生产、可校验、可消费。

本任务正式启动时，需要根据 T01 的真实代码、Schema、错误分布和可用材料重写为完整需求，当前内容不能直接执行。

## 进入前必须具备的输入

- T01 `ACCEPTANCE_REPORT.md` 及用户验收结论；
- 最终导出的 Skill 与公共对象 Schema；
- 字段歧义、多证据、运行记录和错误样例；
- 可用于测试且许可明确、无患者隐私的中医材料候选；
- 用户确认的首个专题、医家或病种范围；
- 金标准由谁标注、谁复核以及可以投入的审核量。

## 预期产物方向

- 首个专题的标注说明和小型人工金标准；
- CaseDistillationSkill 与 TCMReasoningSkill 的版本化契约和实现；
- 教材、医家经验和医案三层对象及证据关系；
- 支持、弱证据、反证、缺失、冲突、主次兼夹和诊次变化表达；
- 自动结果与金标准的对比报告及错误分类；
- 通过 T01 Build、Validate、Query、Trace 的实验包。

以上只是下一任务的产物边界，不代表已经批准样本规模、算法、准确率阈值或正式知识包格式。
