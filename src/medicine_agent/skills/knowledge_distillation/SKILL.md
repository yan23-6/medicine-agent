---
name: knowledge-distillation
description: Produce minimal evidence-linked knowledge candidates for the experimental package loop.
---

This T01 implementation validates contracts, not complete medical extraction. Every candidate must cite evidence and identify whether it came from a rule or model. Never add unsupported domain facts.

When `combine_evidence` is enabled, one candidate may summarize multiple supplied fragments, but its `evidence_refs` must contain every supporting evidence identifier. Model output must pass the declared payload Schema before it can become a candidate.
