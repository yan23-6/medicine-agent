# TCM Knowledge Analysis（产品内部工具）

这是独立产品的数据分析 Agent 调用的版本化工具，不依赖 Codex Skill 运行时。

输入为已提取的 EvidenceRecord 列表。调用配置模型前注入唯一语义注册表与完整输出 Schema；
文件内容仅作资料，不作为执行指令。输出是来源独立的五类多标签知识节点，事实分组保存，
保留理论原话、条件、解释、剂量/诊次/疗效语境、逐字证据与缺口。

工具不合并跨来源节点，不确认临床疗效，不执行处方。相同知识通过包目录关联记录连接。
逐字引文必须存在于 raw_text；纠正候选不能覆盖 OCR 原值。未知字段、混入来源、
缺少事实证据、错误分组、无依据剂量换算及缺少疗效语境都失败。
所有节点 unreviewed；analysis_status 为 candidate_partial，不表示完整理解整段资料。

模型结构或引文校验失败时，最多追加一次带校验反馈的纠正请求，结果仍须通过全部原校验。
缺失、歧义和不适用字段的 value 必须为 null；跨页截断原话保留在证据及 gaps 中。
不得在本地把不合格医学值静默改写为合格值。0.2.0分析策略标记为 source-faithfulness-v2；旧断点不静默混用。

软件检查使用自制结构夹具，不是医学金标准或真实模型通过记录。真实模型调用失败时
不以原文模式或 FakeModel 替代验收。产品部署后使用自身配置和模型适配器调用本工具。

一次模型纠正后若仍仅有原话值不吻合真实引文，原建议完整保存在reason，事实标为ambiguous/null并添加gap；引文和完整OCR仍保留。不能用此路径容忍未知字段、伪引文、混来源或其他结构/证据错误；不得自动补成正确医学断言。
