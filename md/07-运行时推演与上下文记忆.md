# 运行时推演与上下文记忆

## 1. 运行时组成

思维层新增、替换或实质扩展实现前，必须停止执行并询问用户是否确认本次设计；收到明确确认并记录设计版本和范围后才能编码、制作执行性原型/实现测试或委派。设计实质变化须重新确认，通用继续指令不能替代确认。确认前可完善设计与只读分析，独立的数据生产、基础查询和复核任务不受阻；执行规则见tasks/overall/规则与变更策略.md。

```text
统一知识包与标准病例
+ 当前中医专业推理策略与西医未来扩展接口
+ Agent 编排与 Skill 路由
+ 基础模型或已通过评测的后训练模型
+ 上下文与记忆管理
+ 医疗安全策略
= 病例讨论智能体
```

安全策略是独立层，优先级高于专家角色和普通对话指令。

问诊辅助与第 16 章的资料构建共用包目录、证据与版本。一次问诊固定所用包版本和授权状态，包更新不能静默改写进行中的病例。基本包查询只验证产物可消费，不表示问诊已实现；追问、检索和安全路径必须在无 Codex 的独立产品中单独验收。

## 2. 两种推演模式

### 即时知识推演

当没有现成病机链时，系统从知识包检索症状、病因、病位、病性、病机和鉴别节点，临时组合候选路径。该模式覆盖新问题，但结果属于模型候选。

### 已验证路径复用

优先召回已有来源链、经专家确认的链和有相似病例支持的链。该模式更稳定、更容易审计，但不能机械套用到不符合适用条件的病例。

实际运行同时使用两种模式：已验证路径作为先验和参照，即时推演负责处理差异、缺失和新组合。

后训练模型只能改变任务执行方式，不能绕过检索直接宣称其参数中记住的内容是来源事实。涉及病机、方剂、剂量、加减、禁忌和停调时，运行时仍需从当前启用的知识包获取证据，并返回知识包、来源和审核状态。模型权重与当前知识包冲突时，以安全规则、当前证据和明确的审核状态为准。

### 地图式多轮候选循环

用户提出的“类似地图 App”不是照搬导航软件，而是把问诊固化为可重规划的候选状态机：

```text
本轮回答
  → 更新病例观察、时间和不确定项
  → 更新多个候选的支持、反证、冲突与缺失
  → 从当前启用包扩展相关局部知识图
  → 选择最能区分候选且符合安全要求的下一问
  → 新回答后重新规划
  → 达到停止条件时输出候选、证据、不确定性和安全状态
```

每轮记录包版本、召回范围、未命中、候选变化、剪枝依据和未采用分支。查询必须优先走多维分类与局部子图，避免无边界加载全部知识。当前这是一项已固定设计而不是已实现能力；候选评分、信息增益、图扩展深度、剪枝阈值、停止与回退策略在阶段 04 以真实病例和金标准验证。

## 3. 专家思维模拟

专家角色不是语言模仿，而是可配置的推理策略：

- 重点关注的信息；
- 四诊证据使用顺序；
- 病位、病性和邪正判断方式；
- 主病机与兼夹病机组合偏好；
- 相似证候鉴别规则；
- 治法和方药映射；
- 适用范围、禁忌和例外；
- 承认信息不足和提出追问的条件。

系统可以从某位医家视角解释，也可以并列比较多位医家。通用框架的补充必须明确标记，不能冒充医家原话。

## 4. 病例讨论流程

1. 识别用户身份和使用场景；
2. 将输入构造成标准病例，保留原始表述、时间线和不确定项；
3. 并行启动急危重安全检查和当前中医路径；西医路径只保留未来扩展接口；
4. 提取症状、病史、检查、舌脉、阴性信息和时间变化；
5. 路由到相关专科、基础知识、医家经验、指南和病例包；
6. 生成多个假设与专业机制路径，列出支持、弱证据、反证、歧义和缺失信息；
7. 形成当前综合状态、冲突与优先级，安全门不通过时阻断或降级后续建议；
8. 选择少量信息增益最高的追问；
9. 根据回答更新候选，不提前锁定单一结论；
10. 在授权范围内形成目标、治疗或处置算子及具体干预候选；
11. 输出可能性、证据、分歧、来源、安全状态和下一步建议；
12. 仅在授权和必要时保存结构化记忆及后续状态轨迹。

遇到方剂任务时，运行时先调用组合式 FormulaSkill，再由其内部药物层一次性分析整方。单味药基础知识只作为引用输入；方中角色、配伍协同、条件加减、状态变化和停止规则由方剂上下文共同决定，不能把多个单味药结果简单相加。

运行时展示可审计的证据化路径、证明图或决策摘要，不要求输出模型的隐藏思维过程。历史诊断与历史治疗仅作为来源事实，不能自动成为当前建议；反事实和预测状态必须标记为模型候选。

## 5. 上下文优先级

不使用“记忆权重不超过 20%”这类难以验证的描述，而采用以下优先级：

```text
安全规则
  > 当前轮明确事实
  > 已审核知识包与来源证据
  > 当前病例工作状态
  > 经用户确认的历史摘要
  > 普通长期偏好
```

记忆不能覆盖当前证据或安全规则。冲突时展示差异并向用户重新确认。

## 6. 记忆分层

- 会话工作记忆：当前症状、候选病机、已问问题和待确认项；
- 阶段摘要：一段连续讨论的结构化总结；
- 长期偏好：用户允许保存的语言和展示偏好；
- 临床资料：独立的高敏感数据域，不进入普通长期记忆；
- 系统反馈：去标识化、经审核的错误类型，不保留个体身份。

每轮按任务召回少量相关记忆，不加载全部历史。记忆必须可查看、修改、删除，并具有保存期限。
