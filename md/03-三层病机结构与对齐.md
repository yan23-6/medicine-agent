# 三层病机结构与对齐

三层病机结构是中西医平台中的中医专业分支，不是全平台唯一的知识组织方式。它建立在通用证据、标准病例和临床认知对象之上，并与西医专业路径共享观察、诊次、时间、干预、结果和安全状态，但不改写西医概念。

## 1. 三层定义

三层结构不是三套数据格式，而是从统一知识包协议中的证据、语义、推理和对齐对象投影出的三个层级视图。教材、名医材料和医案可以分别贡献不同层的内容，也可以在同一混合数据包中同时贡献多层内容。

### 第一层：通用病机分类

提供跨医家、跨医案的共同参照系，包括发病条件、病因、病位、病性、基本病机、复合病机和病势转化。初版可依据《病因病机学说》形成骨架，但教材只是一个有来源的基础版本，不是不可修改的唯一真理。

### 第二层：名医病机经验

表达一位医家或一个流派如何识别、组合和使用病机，包括关注证据、辨证顺序、核心病机、兼夹病机、鉴别方法、适用条件、治法映射、例外和禁忌。

### 第三层：医案个体病机

表达具体患者在每次诊疗时的证据与病机状态。医案先从原始文本标准化为全平台共用的病例与诊次，再投影为中医个体病机层。必须按首诊、复诊和转归拆分，保存症状、舌脉、检查、阳性证据、阴性证据、弱证据、歧义证据、缺失信息、病机判断、治法、方药和变化。

## 2. 为什么底层不能使用纯树

病机经常存在一因多果、多因一机、本虚标实、寒热错杂、痰瘀互结和动态传变。纯树要求一个节点只有一个父节点，会丢失兼夹和交叉关系。

平台采用：

- 图存储：保存完整关系、时序、条件和冲突；
- 树展示：按基础分类、医家或疾病投影层级；
- 链推演：围绕一个病例显示证据到病机再到治法的路径。

## 3. 病机链组成

标准路径由可选单元组成：

```text
诱因/病因
  → 发病条件
  → 初始病位、病性
  → 核心病理变化
  → 病理产物
  → 脏腑经络影响
  → 症状、舌脉与其他表现
  → 主病机/次病机/兼夹病机
  → 鉴别与反证
  → 治疗靶点
  → 治则治法
  → 方剂选择与整方药物层
  → 加减或停调条件
  → 治疗后病机变化
```

不是每条路径都必须包含全部单元，但缺失部分需要显式标记。

该病机链是通用临床认知链在中医分支中的专业投影。它应当能够回到“观察—标准特征—候选假设—病机—冲突与缺失—综合状态—治疗目标—治疗算子—具体行动—状态变化—响应”，避免从症状直接跳到证型或处方。

## 4. 跨层关系

- `规范化到`：来源术语映射到通用病机概念；
- `细化`：医家经验为通用病机增加条件或子机制；
- `组合`：某经验由多个基础病机组成；
- `实例化`：某医案病机是医家经验的病例实例；
- `支持/反驳`：病例结果对经验提供有限支持或反例；
- `同义/近义/相关但不同`：保留术语边界；
- `演变为`：表示不同诊次之间的病机变化；
- `采用/偏离`：表示实际治法是否遵循某条经验。

## 5. 自动对齐方法

对齐不能只比较节点名称，应联合使用：

- 术语、别名、简繁体和词形；
- 定义、病位、病性和适用范围；
- 前后邻接关系和病机路径上下文；
- 症状、舌脉、治法和方药证据；
- 医家、流派、年代、专科和人群作用域；
- 已有人工确认映射和明确负例。

输出状态包括：已确认相同、自动高可信、候选相同、相关但不同、已确认不同和未判断。高风险或可能错误合并的结果进入人工复核。

## 6. 可审计要求

每个节点和关系都记录：来源、原文位置、陈述主体、生成方式、适用条件、置信度、模型或规则版本、审核状态和修订历史。系统必须区分原文明确陈述、跨段整理、规则推出、模型候选和专家确认。

## 7. 方剂与药物层接入三层结构

方剂不是三层之外的孤立知识。通用层可以提供方剂、药物和治法的规范概念；名医层保存医家的方证、组方、加减和停调经验；医案层保存某次诊疗中的实际方药、剂量、炮制、煎服、反馈和调整。三层通过来源明确的方证、病机、治法和状态变化关系连接。

每个方剂使用一个组合式 FormulaSkill。其药物层由一个方剂级 DrugLayerSkill 统一管理多味药物单元，并同时表达：

- 单味药可跨方复用的固有属性与安全信息；
- 该药在当前方中的剂量、炮制、用法和角色；
- 药物之间的协同、制约、替代和配伍关系；
- 条件加减、观察指标和停止或调整规则；
- 整方作用对应的病机靶点与预期状态变化。

单味药物单元可以被多个方剂引用，但其“方中角色”不能脱离方剂上下文复制为通用事实。

## 8. 经典方法、矛盾关系与状态轨迹

《内经》《难经》《伤寒论》等经典内容作为有来源的知识与方法策略接入中医分支。平台可以表达气血脏腑整体关系、脉经脏腑联动和状态传变等不同方法，但不得把不适用病例强行套入固定证名、六经或方证。

本虚与标实、推动与阻滞、温煦与凝滞、升运与壅滞、整体与局部、慢性与急变等并存关系可以记录为病机冲突或矛盾对象。该对象用于组织主次、缓急、治疗目标和组合约束，不直接推出特定方药或疗效结论。

多诊次病机使用“当前状态 + 实际行动 → 下一状态 → 实际响应”组织。历史治疗、平台候选和现代建议分别保存；没有复诊证据时不得生成虚构转归。反事实路径只能作为理论候选或训练视图，不能回写为真实病例事实。
