# 稳定设计总览

`md/` 只保存当前稳定产品和技术设计，不记录阶段进度。当前实现状态见 `tasks/STATE.md`，当前执行见 `tasks/CURRENT.md`。

## 核心设计

1. 当前研发以中医为主，西医只保留通用主干和未来 Profile/接口；
2. 中医知识覆盖基础理论、中药、辨证、方剂和病例，基础理论是辨证基础；
3. 事实层唯一，来源节点独立；相同概念通过可审计候选关系连接，不覆盖原文；
4. 分类是多维可重建视图，不使用一棵固定目录树承载全部语义；
5. 问诊采用地图式候选状态机，只扩展相关局部知识图；
6. 原文、OCR、模型候选、用户更正和专家确认分层；
7. 字段、分组、节点和单元可局部隔离，身份、来源、证据和包完整性失败必须阻断；
8. 知识包是可迁移事实载体，LadybugDB 是未来可重建工作层；
9. 产品运行不依赖 Codex；Agent 只能调用已登记并验收的 Skill；
10. 医疗安全和人工评审优先于自动推演与处方。
