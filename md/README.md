# 中医病机知识蒸馏与智能体平台：设计文档总览

> 状态：方案基线 v1.4  
> 固化日期：2026-09-19  
> 核心主线：病机  
> 核心结构：通用病机分类—名医病机经验—医案个体病机  
> 技术原则：一次证据抽取、双视图生成；图存储、树展示、链推演；方剂 Skill 组合化、药物层统一管理；检索与后训练分工；LadybugDB 嵌入式运行；核心平台独立运行、多环境薄适配

## 项目定义

本项目建设一套可独立运行的中医病机知识蒸馏与临床推理支持平台。平台从教材、名医经验、医案、论文等材料中抽取有原文依据的知识与推理片段，构造通用病机、名医经验、个体医案三层可审计结构，并通过 Web、MCP、REST API 和环境适配包供不同智能体调用。

平台用于中医知识研究、教学、医案整理和医生辅助，不替代执业医师，不直接面向患者作出确诊或开具具体处方。

## 已固定的核心决策

1. 病机是知识组织和智能体推演的主线，但必须连接病因、病位、病性、证候、四诊、治法、方药及转归。
2. 所有蒸馏产物遵守同一套项目级“统一知识包协议说明书”；每份材料形成一个可独立使用的数据包，包内保存知识节点、来源推理片段、原文证据和最小机器自描述，但不重复附带独立说明书。
3. 不建立两套相互独立的知识副本；基于唯一证据层生成知识视图与病机推理视图。
4. 病机专题蒸馏负责把已有知识与推理片段连接为完整路径；没有预构建路径时，知识包仍可用于即时推演。
5. 病例提高的是特定条件下某条路径的经验支持度，不直接证明医学正确性。
6. 三层结构底层采用图，面向用户显示为树，面向病例分析展开为链。
7. Skill 负责流程、路由和质量控制，医学内容存放在独立、可版本化、可热插拔的知识包中。
8. 核心平台必须脱离任何智能体独立运行；Cursor、ChatGPT/Codex、DeepSeek Harness 等只使用薄适配层。
9. MCP 是智能体接入的主要公共接口，REST API 与 SDK 是程序接入和兼容兜底。
10. 医疗安全策略独立于角色提示词，并具有更高执行优先级。
11. 默认图数据引擎确定为 LadybugDB，作为应用内部组件运行，不要求用户安装或维护独立数据库、Docker 或额外数据库服务。
12. 知识数据包与运行数据库分离：数据包是可复制、可校验的交换产物；平台发现数据包后，将其纳入统一的 LadybugDB 工作库和联合索引。
13. 同一科目的教材、论文、名医经验和医案包可以同时启用、共同查询，但所有来源节点和版本边界必须保留。
14. 多环境支持通过不同的轻量适配方式逐步实现；LadybugDB 和必要检索扩展应随对应平台发行物一起提供，尽量避免运行时额外下载依赖。
15. 教材、论文、名医经验和医案不是四套数据结构，而是统一结构下的资料类型配置；统一核心对象保持一致，不适用部分允许为空，可按资料类型增加受控扩展。
16. “复制即用”的前提是数据包声明的协议版本兼容且通过完整性、安全和许可校验；新增普通数据包不新增说明书，只有统一结构语义变化时才升级项目级说明书。
17. 当前仍处于需求评审阶段，只固定蒸馏产物的逻辑结构、能力边界和技术选型，不在本文档体系中提前固定代码目录、数据库表、内部文件名和接口字段。
18. 一个方剂只发布一个组合式 FormulaSkill；方剂识别、病机解释、药物层、加减、状态转移、停调、方剂选择和方剂比较是其内部能力，不按每味药拆成可独立安装的顶层 Skill。
19. 药物层采用“一个药物层 Skill 管理多味药物单元”的结构。单味药的固有属性可复用，剂量、炮制、配伍角色、协同制约和条件加减必须绑定具体方剂、来源和适用状态。
20. 后训练不承担医学事实存储。知识包和检索负责提供可更新、可追溯的医学事实，后训练负责教会模型稳定执行结构化任务、遵守证据边界、使用工具并满足安全约束。
21. 后训练作为项目后续正式阶段预留。当前只持续保存证据、专家修订、错误类型和可复现基线；待智能体结构、蒸馏结构和核心链端到端跑通后，依据届时项目快照另行固化具体训练、安装和验收方案，审批通过后才执行。
22. 平台内的蒸馏、问诊、病机、方剂、药物、评审和安全 Skill 共同服务“材料—知识—问诊—辨证—治法—方药—状态变化—随访再辨证”的核心链，不建设互不关联的 Skill 集合。

## 阅读顺序

首次了解项目时按编号阅读。开发单个模块时，先读本页和对应模块文件；任何局部设计不得违反本页“已固定的核心决策”。如确需改变核心决策，应先修改本页、记录原因和版本，再同步修改受影响文档。

关于蒸馏后数据包结构和项目级“说明书”的规范性定义，以 [04-知识包与证据数据模型](04-知识包与证据数据模型.md) 为唯一主文档；其他文件只描述该协议在各模块中的使用方式，不另行定义竞争版本。
