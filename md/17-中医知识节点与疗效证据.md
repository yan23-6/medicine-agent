# 中医知识节点、五类分类与疗效证据

> 修订：2026-10-15；用户要求的当前建设范围。
> 本文说明逻辑，逐字段唯一规范仍为 `src/medicine_agent/semantics/registry.json`。
> 首版历史基线（本轮B4修复另见文末）：用户澄清相同知识不必合并后恢复建设。语义注册表 0.3.0、结构化分析工具、实验包扩展、非破坏性关联和查询已实现并有离线检查；两个自制短材料已通过真实模型分析、产包校验及隔离安装后的回查/关联检查；用户已暂时认可首版试用，逐条医学正确性未验收。

## 1. 当前重点与五类知识

当前产品以中医资料分析和中医知识利用为重点。通用来源、证据、时间、安全和病例主干保留；西医只保留可版本化扩展入口及既有历史诊断记录，不在本轮扩充西医推理或术语包。

知识节点可同时属于中医基础知识、中药材知识、中医辨证知识、中医方剂知识、临床案例五类。类别描述知识内容，教材/论文/医案集描述来源，科目/专题描述检索组织，原有通用病机/医家经验/个体医案描述知识层次，四者互不替代。

“辨证”是临床应用的关联中心：四诊观察、症状、体征、病因、病位、病性、病机、证候、鉴别、治则治法、选方条件、药物角色、个体化调整与诊次转归相连。基础理论有自身完整结构，不能被缩减为这些临床字段。病名、证候、病机和方剂不是同一个节点，也不建立无条件的“症状即证型”“证型即处方”映射。

一个节点允许多个内容结构，例如同时保存药材的药性知识与辨证适用条件。每条事实都指向原文证据，缺失值保留空值与缺失原因，不通过模型常识填满。字段丰富代表能表达，不代表每份资料都包含全部内容。

## 2. 节点与关系

节点共同保存稳定身份、原文名称、别名、五类标签、内容结构、来源与证据、生成方式、审核状态、适用条件、概念对齐候选、缺口及关系。同一知识的不同来源各保留独立节点，用关联记录连接。即使定义相同也不强制合并；查询时可展开多个来源，原文、解释、分类和冲突分别保留。名称相同只提供关联线索，不能自动确认同义。具体规则见下文。

基础知识使用下文“概念＋理论命题＋来源解释”的结构，覆盖理论体系、基本概念、属性功能、相互关系、规律、推演、学说与争鸣；不要求每条基础知识具有症状、证候、治法或疗效。
药材包括基原、药用部位、产地采收、鉴别质量、炮制、性味归经、升降浮沉、毒性、功效主治、适应证候、剂量/单位/换算依据、煎服法、配伍、禁忌、相互作用、不良反应和贮藏。
辨证包括四诊、主次症、舌脉细分、肯定/否定、时间与诱因、辨证体系、病机要素及主次兼夹、依据/反证/缺失、鉴别、治则治法、选方用药条件和动态变化。
方剂包括出处与版本、原方、组成、君臣佐使及依据、药量与炮制、剂型与制法、方义、功效、主治、适用条件、禁忌、加减触发、停调条件及异方同名/同方异名。
病例包括去标识患者概况、体质、主诉病史、时序诊次、四诊检查、辨证、实际历史干预、个体化处方、加减原因、共同干预、依从性、不良反应、复诊、转归、复发和随访缺失。

药材固有属性与方中角色分开，经典方与患者实际处方分开，来源历史用法与平台现代建议分开。病例观察仍复用通用事实，不删除已实现的通用契约。

## 3. 基础知识重新设计：概念与理论命题

五大类是知识分类，不是五张字段固定且互斥的表。基础知识中至少区分两种对象：概念保存“在说什么”，理论命题保存“对它说了什么”。例如“甘味”是概念，“甘能缓急”是关于甘味作用的命题；同一概念可以连接很多命题，不能把这些命题都塞进一个定义字段。

### 3.1 理论专题可多选、可逐级扩展

初始覆盖：中医学理论体系与思维方法、精气学说、阴阳、五行、藏象、精气血津液神、经络与形体官窍、体质、病因与发病、病机与传变、治则与治法、养生与预防、五运六气，以及与基础理论交叉的药性、四气五味、升降浮沉和配伍原理。

这些是初始专题树，不是封闭枚举。新资料涉及其他学说、古籍注释或新的理论表达时，可以登记专题或进入待细分区；必须保留完整片段并报告结构缺口，不能因不符合既有栏目而丢弃。专题与五大类分别保存，例如药性理论可同时属于“中医基础知识”和“中药材知识”。

### 3.2 需要表达的字段组（逻辑设计，尚非运行时字段字典）

| 字段组 | 要保存的内容与意义 |
| --- | --- |
| 概念身份 | 名称、原文用语、别名、定义、概念类型、上下位概念、所属学说；区别同名异义与异名同义 |
| 命题本身 | 完整原始命题、便于检索的概括、命题类型；定义、属性、功能、关系、规律、分类、条件规则、理论推演或争鸣分别表达 |
| 命题涉及对象 | 主体、谓词、客体及其他参与对象、各自角色、作用方向；支持多对象、多个分句，不能强迫所有理论变成简单二元关系 |
| 逻辑结构 | 并列、先后、依赖、条件、例外、否定、程度、量词和可能性；保留“能”“常”“必”等原文差别，不能一律变成必然成立 |
| 理论含义 | 原来源自己的释义、关键词解释、理论层级、是否类比/象思维/生理描述/病理解释/治疗原则；不能默认都是现代实验因果关系 |
| 解释路径 | 前提、理由、中间步骤、结论、依赖的其他命题和原文论证；没有论证就标未提供，模型补充的分析另列候选 |
| 条件与边界 | 适用范围、成立条件、时令/人群/状态、例外、禁用推论、容易误解处；未提条件不等于无条件通用 |
| 理论联系 | 与脏腑、精气血津液神、形体官窍、药性、其他学说的关系；临床症状、证候、治法仅在来源涉及时连接 |
| 学术差异 | 医家、流派、时代、版本、异说、解释差异、争议和更正；不能用较新来源覆盖较老解释 |
| 来源与完整性 | 每个原文片段及其定位、上下文、逐字段证据、分析方式、审核状态、遗漏和未理解内容 |

长论述保留完整证据，同时拆成可关联的小命题；拆分后的命题通过共同段落与论证顺序保持整体意义。字段允许不适用，不用虚构症状或疗效来补齐。

### 3.3 用用户给的两个例子检验

| 输入原话 | 如何保存 | 不应发生什么 |
| --- | --- | --- |
| “甘能缓急” | 原话不改；概念“甘味”和“缓急”，命题类型为药性作用/理论规律；专题可挂五味、药性；五大类可同时挂基础知识、药材知识；具体释义与适用条件按每个来源分别保存 | 不强行填患者症状、证候和处方；不据此推断所有甘味药在所有情况下都能治相同疾病 |
| “发乃气血之余” | 原话不改；标记涉及“发”“气”“血”的理论解释，保留原来源对“余”的含义和论证；可关联形体官窍、精气血、藏象等有依据专题 | 不默改成“发为血之余”；没有出处时不补古籍作者、经典出处或具体生理因果链 |

“发乃气血之余”与检索中常见的“发为血之余”是否表达同一命题，要比较原文和解释后判断；原始文本即使有误写或 OCR 疑点，也仅增加纠正候选，绝不覆盖。

## 4. 来源节点独立，相同知识通过地址关联

### 4.1 保存结构

教材节点 A ← 关联记录 → 论文节点 B。两边分别保留原文、位置、解释、分类和结构化事实，关联不修改任一来源包。

- **来源节点**：来源身份、标题、概括、五类标签、专题、原文证据、分组事实、缺口和审核状态。不同来源的相同定义仍为不同节点。
- **原文证据**：完整截取文字/OCR 原值、来源版本、文件指纹、页码/章节/区域、上下文、提取方式、纠正候选与确认状态。每个结构化事实可引多段证据；规范值和解释不能覆盖原文。
- **关联记录**：独立标识、起点与终点地址、关系类型、理由、候选状态、内容校验。地址由 package_id 与 node_id 组成，不依赖盘符、文件夹名、开发会话或数据库行号。

来源身份参与节点标识。内容完全相同但来自不同文件，仍分别保存来源与出现位置。一个来源多处提到相同知识，也保留原文证据与上下文；仅完全相同的内容身份用于去重，不能按名称覆盖。

### 4.2 教材与论文的例子

```text
教材节点 A：甘能缓急
  原文：<教材实际截取文字，保持原样>
  解释：<教材自己的解释与条件>
  分类：基础知识
  地址：(教材包 ID，节点 A ID)

论文节点 B：甘能缓急
  原文：<论文实际截取文字，保持原样>
  解释：<论文自己的解释与条件>
  分类：基础知识、药材知识
  地址：(论文包 ID，节点 B ID)

独立关联：A ↔ B，关系可为“同一定义（候选）”或“相关”
查询展开：同时显示 A、B，各自原文不变；分类视图为两者并集
```

上例为占位示意，不是实际医学原文。教材/论文是来源类型；五大知识分类、专题、来源类型分别汇总，不能互相替代。查询并集只计算本次实际展开的节点，来源依据可通过各节点回查；不写回或扩张任一来源自己的分类。

### 4.3 关联、差异与更新

1. 当前支持 same_definition（同一定义候选）、related（相关）、expands（补充解释）、contradicts（相互矛盾）；查询从任一端都能找到另一端，语义方向保留。
2. 相同名称或别名自动提供关联线索，不自动建立已确认等价。显式关联也只是候选，不能当专家确认。主题相同、命题相同、条件相同是不同判断。
3. 新来源新增节点与关联，不改写旧节点。修改内容产生新身份和不可覆盖修订；旧引用不自动重指新内容。需要关联新版时新增对应关系。
4. 不同解释、条件、否定和争鸣分别保存，即使关联为同一定义也不压成统一解释。关联本身不证明医学结论正确。
5. 原文片段可通过证据引用复用，不能因摘要、去重或关联丢掉任一来源的文字、位置和上下文。
6. 论文转引教材时保存实际读到的论文文字与引用说明；未核验教材不能生成教材原文。转引识别与证据独立性判定仍须后续专项验收，不能由关联数量推出验证次数。

### 4.4 热插拔与迁移

完成包以 .medpkg 单文件保存于固定知识目录；links 为包内资源，由运行时管理，带版本和内容校验，不是只存在内存的索引。来源分区不是最终交付目录。

- 移走某个来源包：只标记引用目标暂不可用（target_unavailable）；保留关联记录，其他包原文与节点不变，不能以缺包为由删除数据。
- 放回相同身份来源包：重新扫描后恢复 resolved，不需重新运行模型。
- 复制全部结果到另一电脑：复制所需 .medpkg 文件；单个自包含派生文件已内置继承来源和 links，无需原文件、工作区、模型或 Codex 即可回查。
- 单个文件只能声称拥有其中实际保存的来源。B2派生时携带全部基础内容及可取得的关联依赖；原本已缺失的外部目标保留未解析地址，不能伪造其原文。
- 关联文件损坏单独报告，不能覆盖或污染原来源包；目标包本身无效时不纳入查询，引用仍保留待恢复。

## 5. 疗效不能只用一个“有效”字段

分开记录：来源声称的功效、单例实际观察、病例系列、研究对照结果、前临床结果和模型预测。疗效记录包含评价对象、指标/量表、治疗前值、治疗后值、单位、变化、观察时间、疗程、比较组、样本/分母、事件数、失访、复发、不良事件、患者/医生评价、共同干预、混杂、证据局限和因果边界。

没有随访不能补成治愈；“未提不良反应”不等于“没有不良反应”；没有分母的有效率仍可保留为来源陈述，但须显示缺口。单例改善、历史“愈”或模型预测不自动证明方剂有效，也不能提升成所有患者的结论。

## 6. 分析与交付

用户对分析首版的暂时认可不等于知识逐条确认。后续复核与更正记录采用独立追加层，见[第 18 章](18-候选复核与更正记录.md)；既有来源、原话和推断/歧义状态不被覆盖。

数据分析 Agent 调用版本化中医结构分析工具，返回五类节点和带条件/证据的关系。结构验证、字段证据验证、节点与关系引用、类别与内容结构匹配、来源身份、疗效语境及缺失信息均为检查项。

本轮先在唯一语义注册表登记增量字段，再实现 domain/tcm_knowledge.py 和 tcm-knowledge-analysis@0.1.0。模型模式调用新工具，原文模式仍只做原文候选。新工具读取注册表并逐字段检查证据、来源、缺失状态、分组、剂量换算依据及疗效语境。完整结构作为 tcm.json 与 extensions.json 保存并纳入 manifest 校验，查询提供节点、所有相关证据及非合并的关联展开。说明书由注册表自动生成，见[字段说明书](中医字段说明书.generated.md)。

离线检查覆盖五类结构、理论不强制症状、逐字证据与来源隔离、多分类、缺失值、推断依据、剂量换算、疗效语境、未知扩展隔离、多来源关联不改写来源包、卸包/重插及目录迁移。真实资料下的命题拆分、复杂论证完整性、自动对齐准确率、转引识别和医学正确性尚未验收，不能以 Schema 通过证明理解透彻。图的 analysis_status 固定为 candidate_partial，保留 gaps；不能把“所选页已处理”当成“全部医学内容已理解”。

原文模式只产生原文候选与未分类状态，不假装完成医学结构分析。真实模型不合格输出不能生成正式或看似完整的医学包。新对象作为可校验实验包扩展保存，旧 T01/T02 包保持可读；新消费者必须识别扩展版本，未知扩展不静默忽略。

旧工作区不静默改写：分析契约或语义版本变化时，已完成旧包可读取；未完成旧断点明确提示版本冲突，需另建分析任务。不是删除原始文件或旧产物。

## 7. 联网依据与使用范围

以下用于结构设计，项目字段是基于这些资料的工程整合，不宣称逐字等同外部标准，也不复制受限完整术语或药典正文。

- [WHO 中医术语（2022）](https://www.who.int/publications/i/item/9789240042322)：基础理论、诊断和治疗术语边界。
- [GB/T 16751.2-2021 证候标准元数据](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=C71A9DAD24CB1252F12439D1F045DA6A&refer=outter)：证候身份与标准版本；治法另外记录，不能同名混用。
- [2025 年版药典实施公告](https://www.nmpa.gov.cn/xxgk/fgwj/gzwj/gzwjyp/20250325184202175.html)：药材/方剂质量标准和版本引用的治理依据；公告不能替代具体药材正文。
- [CONSORT 中药复方扩展](https://www.equator-network.org/reporting-guidelines/consort-chinese-herbal-medicine-formulas/)：方剂、辨证适用范围、组成、干预和研究结果的可追踪性。
- [CARE 病例报告清单](https://www.care-statement.org/checklist)：病史/时间线、干预变化、患者和医生结局、依从性、耐受、不良事件及随访。
- [北京中医药大学《中医基础理论》课程](https://www.icourse163.org/course/BUCM-1206410812?tid=1452035486)：基础理论具有独立的学说、生理、物质与相互关系范围，不等同于临床辨证表格。
- [国家标准公开通知中的 GB/T 20348-2026《中医基础理论术语》](https://openstd.samr.gov.cn/bzgk/std/nd?no=2721)：核验标准身份及 2026-07-01 实施日期；本轮未取得其全文，不据此声称已导入完整术语或标准字段。
- [《中草药》：中药甘味的药性表达及在临证配伍中的应用](https://www.tiprpress.com/zcy/html/2016/4/20160401.htm)：药性理论与临床配伍的交叉资料线索，不将理论陈述直接当成已证实疗效。
