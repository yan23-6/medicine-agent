# docs 目录规则

`docs` 保存导师提供的原始材料和参考数据，只作为分析输入与来源参考。

- 默认只读：AI 不得修改、重命名、删除、移动、覆盖或重新导出本目录中的任何既有文件。
- 不得为了统一格式、纠正 OCR、清理内容或补充注释而改写原文件。
- 对材料的结构化结果、摘要、评审意见和可吸收设计，应写入 `md`、知识包候选区或其他明确的工作目录，不回写 `docs`。
- 引用材料时保留文件身份、原文与模型分析边界；疑似错误只能标记为待核，不能在原文件中擅自更正。
- 只有用户明确点名具体文件并要求修改该文件时，才可临时突破只读限制；修改范围不得扩展到其他文件。
- 本规则本身只有在用户明确要求调整 `docs` 规则时才可修改。
